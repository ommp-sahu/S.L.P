S.L.P (Smart Lifestyle Planner) 🏋️‍♂️
S.L.P is a comprehensive web application designed to empower users to take control of their fitness journey. By combining a sleek, intuitive UI with modular tracking logic, the platform helps users set, monitor, and achieve their health and lifestyle goals.

🚀 Live Demo
You can view the live project here: S.L.P Live Site

✨ Features
Personalized Onboarding: Tailored setup through the login.html and goal.html modules.

Structured Training: Organized workout splits (split.html) and detailed exercise logs (exercise.html).

Progress Tracking: Dedicated history and summary sections (history.html, summary.html) to visualize long-term consistency.

Responsive Design: Fully optimized for mobile and desktop viewing using modern CSS techniques.

Modular Architecture: Built with clean separation of concerns between HTML structure, CSS styling, and JavaScript logic.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom animations and layout)

Scripting: JavaScript (ES6+) for dynamic UI updates and logic

Deployment: GitHub Pages
